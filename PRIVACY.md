# Publication privacy

## Publication activity timestamps

Author and committer dates in this publication are disclosed synthetic UTC
counters. They are identifiers, not real development, publication, work or sleep
times. Original records remain in private recovery storage. All preexisting
trees, file contents and modes, commit messages, source/execution identifiers,
non-date headers and parent relationships are preserved. This note is the only
new source file. Runtime behavior and third-party licenses are unchanged.

This metadata treatment does not clear report clocks, date-only records,
timestamp-bearing provenance references, images, hosting events, hidden refs,
caches or external copies. Those require separate contextual review. Ordinary
deployment paths, device models/counts and generic protocol/example dates are
not cleanup targets. Product tests from previous revisions are not claimed as
new executions by this metadata-only publication.
